# Contributing to Deep World Model

Thanks for your interest. Code, SDKs and examples are not public yet, so the most useful things right now are:

- **Star or watch** this repository to be notified when the SDKs, MCP server and ROS 2 package land.
- **Open an issue** with the use case you'd build on a live, semantic 3D model: venue type, robot or agent stack, and which API surface (geometry, semantics, routing, change feed) you need first. This directly shapes the roadmap.
- **Contribute captures** through the [Beetle app](https://deep3d.world/#contribute). Every walk‑through keeps a venue's model current.

For partnerships, venue onboarding or API access, email **info@collectiv.co**.

Once code is published, this file will cover development setup, coding standards and the pull request process.
